## 一、项目概述

### 1\.1 项目行业背景与痛点

我国老龄化人口规模持续增长，居家养老、社区养老成为主流养老模式，传统养老服务存在**医患对接难、健康档案零散、文娱活动无系统化管理、养老物资缺少积分兑换渠道、养老资讯分散**等行业痛点：

1. **问诊就医不便**：老年人寻找专科医生资源繁琐，线下预约挂号路程远、流程复杂，缺少线上查看医师、预约问诊渠道；

2. **健康数据无留存**：老人体检、就诊健康信息纸质存档易丢失，无法长期跟踪身体健康变化；

3. **文娱养老无统筹**：社区养老文娱活动、书画课程、养生科普零散组织，老人无法便捷查看活动、报名参与；

4. **养老激励体系缺失**：缺少积分激励机制，老人参与活动无福利兑换渠道，参与积极性不足；

5. **服务信息不对称**：养老政策、养生公告、健康科普资讯无法统一触达老年用户。

基于以上痛点，**智慧养老服务系统**落地开发，采用「**普通养老用户端 \+ 医生端 \+ 系统管理员后台**」三角色架构，打通线上问诊预约、健康档案管理、文娱活动、养生科普、积分商城、公告留言全链路养老数字化服务，实现社区智慧养老全流程线上化管控。

### 1\.2 项目建设目标

1. **三角色权限分级管控**：划分普通用户（老人）、入驻医生、平台管理员三类角色，权限隔离，各司其职；

2. **医疗健康闭环管理**：实现医生档案查看、线上预约就诊、预约取消、体检建档、健康信息全生命周期存档；

3. **养老文娱数字化运营**：整合养生视频、艺术字画鉴赏、线下娱乐活动三大文娱模块，线上浏览 \+ 活动报名一体化；

4. **积分激励福利体系**：搭建积分商城，老人参与活动累计积分，可兑换生活用品，提升养老活动参与度；

5. **资讯互动一体化**：公告发布 \+ 留言板互动，实现养老资讯推送、用户意见反馈双向互通。

### 1\.3 系统整体架构

系统采用 B/S 前后端分离架构，整体分为**前台养老用户门户端、医生功能端、管理员后台管控端**三层：

- **前台用户端**：面向老年使用者，首页聚合全系统导航，包含医生、养生视频、字画鉴赏、娱乐活动、积分商城、留言板、公告七大核心栏目；

- **医生端**：医生账号注册登录，管理个人出诊信息、处理用户预约问诊；

- **管理员后台**：全平台数据管控，覆盖用户、医生、科室、预约、体检、文娱、商城、公告全模块配置维护。

## 二、系统详细功能模块设计

### 2\.1 登录注册模块

系统提供两套登录页面，区分**用户 / 医生两种注册入口**：

1. **登录页**：双风格登录 UI，表单填写账号、密码，勾选身份（用户 / 医生）完成登录；

2. **注册页**：用户注册需填写账号、姓名、密码、性别、年龄、手机号、身份证、头像，系统默认初始积分 0；医生独立注册入口，完善医师执业信息后由管理员审核开通权限；

3. **表单校验**：密码一致性校验、手机号 / 身份证格式校验，防止非法注册。

### 2\.2 前台用户功能模块（老人使用端）

顶部统一导航栏：首页、医生、养生视频、艺术字画鉴赏、娱乐活动、积分商城、留言板、公告信息、个人中心、退出登录。

#### 2\.2\.1 首页模块

轮播医疗主题 banner，首页分区展示精选公告、热门医生、近期文娱活动快捷入口，作为全系统导航枢纽。

#### 2\.2\.2 医生模块

1. **科室分类筛选**：左侧科室侧边栏，一键筛选对应科室全部医师；

2. **医师卡片展示**：卡片排版展示医生头像、姓名、所属科室、入驻时间；

3. **预约问诊**：点击医师卡片查看详情，提交线上就诊预约申请，生成预约单据存入后台。

#### 2\.2\.3 养生视频 / 艺术字画鉴赏模块

分类展示养生科普短视频、书画鉴赏图文资源，支持在线浏览查看，老人随时随地学习养生知识、赏析艺术作品，浏览内容可累计活动积分。

#### 2\.2\.4 娱乐活动模块

卡片展示社区线下养老文娱活动封面、活动名称、举办时间；点击查看详情、在线报名参加活动，报名成功后自动发放对应活动积分。

#### 2\.2\.5 积分商城模块

1. **商品详情浏览**：展示养老生活用品图片、商品名称、详情、库存数量、所需兑换积分；

2. **积分兑换**：用户消耗个人账户积分兑换对应商品，生成兑换订单由后台统一处理。

#### 2\.2\.6 留言板 \& 公告信息

- **公告**：查看管理员发布的养老政策、健康通知、活动预告；

- **留言板**：用户在线提交养老相关疑问、服务建议，管理员后台回复答疑。

#### 2\.2\.7 个人中心

用户修改个人资料、修改登录密码、查看我的预约记录、我的兑换订单、个人积分明细。

### 2\.3 管理员后台管理模块

左侧树形菜单栏，全平台统筹管控，细分 12 大管理子模块：

#### 2\.3\.1 用户管理

全平台注册老人信息台账，支持用户查询、新增、编辑、禁用、分页管理，查看用户基础信息与积分余额。

#### 2\.3\.2 医生 \& 科室管理

1. **科室管理**：新增 / 编辑 / 删除科室分类，作为医生挂靠基础分类；

2. **医生管理**：审核医生注册申请、维护医师信息、上下架医生资料，管控平台医师资源。

#### 2\.3\.3 预约就诊 / 预约取消管理

汇总所有用户问诊预约单据，查看预约状态（待接诊 / 已取消 / 已完成），处理用户取消申请，归档就诊记录。

#### 2\.3\.4 预约体检 \& 体检健康信息管理

老人预约体检单统一管理，体检结束后录入体检报告、健康指标数据，建立老人终身电子健康档案。

#### 2\.3\.5 养生视频 / 字画鉴赏 / 娱乐活动管理

管理员自主发布、编辑、下架对应资源 / 活动，填写名称、时间、地点、配图、积分、内容详情，前台实时同步展示。

#### 2\.3\.6 积分商城 \& 兑换积分管理

上架积分兑换商品（填写名称、详情、库存、所需积分、商品图），管理用户积分兑换订单，审核发货。

#### 2\.3\.7 留言板 \& 系统管理

回复用户留言、发布平台公告；配置系统基础参数、后台账号权限。

## 三、项目技术选型

### 3\.1 后端技术

- **核心框架**：SpringBoot \+ MyBatis\-Plus，简化开发配置，高效处理预约、健康档案、商品等多表业务；

- **数据库**：MySQL8\.0，存储用户、医生、预约、商品、健康档案结构化数据，事务保障积分扣减、订单生成数据一致性；

- **安全框架**：Shiro 实现 RBAC 角色权限，隔离管理员、医生、普通用户数据访问权限；

- **文件存储**：本地 / OSS 双存储，存储医生头像、活动配图、商品图片。

### 3\.2 前端技术

- **前台用户端**：HTML5\+Bootstrap\+Vue，响应式页面，卡片式布局适配老年用户视觉习惯；

- **管理后台**：ElementUI\+Vue，左侧菜单栏 \+ 标签页 \+ 数据表格经典后台布局，弹窗表单完成新增修改。

### 3\.3 部署

项目打包 Jar 包，Windows/Linux 服务器一键部署，搭配 Nginx 加速静态图片访问，社区养老机构、民政部门均可低成本落地部署。

## 四、项目核心亮点

### 亮点 1：全链路养老闭环，一站式覆盖医养文娱全需求

区别单一养老挂号系统，系统**医疗问诊 \+ 健康建档 \+ 文娱活动 \+ 积分福利 \+ 资讯互动**五大业务一体化，完整覆盖老年人日常就医、休闲、福利全场景，贴合社区居家养老实际运营模式。

### 亮点 2：积分激励生态，盘活社区养老活跃度

首创「参与活动→获取积分→商城兑好物」闭环激励，用实物福利激励老人主动参与文娱、养生学习，从运营层面解决社区养老活动参与率低的行业难题。

### 亮点 3：电子健康档案永久留存，实现老人健康全周期追踪

线上归档历年体检、就诊数据，打破纸质档案易丢失弊端，家属与管理人员可随时查阅健康记录，辅助慢性病长期养护。

### 亮点 4：多角色精细化权限，适配机构运营管理

管理员统筹平台、医生专注问诊、老人使用服务，三方权限隔离，适配养老服务中心、街道社区养老站的规范化运营。

### 亮点 5：UI 适配老年群体，操作轻量化

前台大卡片、大字式排版，简化冗余操作，降低老年人上网使用门槛；后台规整表单便于管理员批量维护数据。

### 亮点 6：模块化拓展性强

预留拓展接口，可快速新增居家上门护理、助餐预约、远程问诊视频等功能，适配后续养老业务迭代升级。

## 五、落地应用场景与项目价值

### 5\.1 落地场景

1. **街道 / 社区养老服务中心**：搭建社区专属智慧养老平台，统筹辖区老人文娱、问诊、福利服务；

2. **民办养老院 / 日间照料中心**：院内数字化管理，统一管理住养老人健康、院内活动、物资兑换；

3. **区县民政养老部门**：区域性养老数据汇总监管，统计辖区老人健康、养老服务落地数据。

### 5\.2 落地价值

1. **老年用户**：足不出户线上找医生、报活动、兑生活用品，降低养老办事成本，丰富晚年文娱生活；

2. **养老运营方**：数字化管控全业务，减少纸质台账人工成本，用积分运营提升老人粘性；

3. **社会层面**：助力传统养老向数字化智慧养老转型，完善社区居家养老配套体系，赋能国内养老产业升级。

## 六、项目总结

智慧养老服务系统是一款**贴合国内社区养老刚需、落地实用性突出**的垂直养老数字化平台，依托三角色分层架构、医养文娱一体化、积分激励体系、电子健康档案四大核心能力，解决传统养老就医难、管理乱、文娱匮乏、服务零散痛点。系统部署成本低、易拓展、适配老年使用习惯，在社区养老、机构养老领域具备极高落地与推广价值。
